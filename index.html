Alphabetical Design Lexicon

Scroll through the directory below to explore computational vocabulary while monitoring your exact reading progress in real time.

A

Algorithm

A step-by-step problem-solving procedure or mathematical sequence of operations.

B

Bandwidth

The maximum rate of data transfer across a given path in a network.

C

Concurrency

The ability of different parts of a program to execute out-of-order without affecting the final outcome.

D

Deadlock

A state in which two or more competing actions are each waiting for the other to finish.

E

Encryption

The process of encoding information to prevent unauthorized interception.

F

Framework

A universal, reusable software platform providing generic functionality.

G

Garbage Collection

Automatic memory management that reclaims resources allocated to unused objects.

H

Hashing

Transforming arbitrary keys into fixed-size values via deterministic hash functions.

I

Interface

A shared boundary across which distinct software components exchange information.

J

JSON

JavaScript Object Notation, a lightweight open-standard data interchange format.

K

Kernel

The central core module of an operating system managing CPU, memory, and devices.

L

Latency

The time interval between the stimulation and response in a computing network.

M

Mutex

A mutual exclusion locking mechanism used to synchronize access to shared resources.

N

Node

A basic unit of a data structure, graph, or network topology capable of handling messages.

O

Optimization

Modifying software systems to make work execute more efficiently with fewer resources.

P

Paging

A memory management scheme by which an OS retrieves data from secondary storage into pages.

Q

Queue

A first-in, first-out (FIFO) linear data structure for task scheduling and packet buffering.

R

Recursion

A method where the solution to a problem depends on solutions to smaller instances of itself.

S

Semaphore

A variable or abstract data type used to control access to a common resource in concurrent systems.

T

Throughput

The amount of work or data processed by a system in a given period of time.

U

Unicode

An information technology standard for the consistent encoding of text across languages.

V

Virtualization

Creating a virtual rather than actual version of operating systems, servers, or storage devices.

W

WebSockets

A computer communications protocol providing full-duplex communication channels over a single TCP connection.

X

XSS

Cross-site scripting, a vulnerability enabling attackers to inject client-side scripts into web pages.

Y

Yield

An action causing the executing thread to temporarily pause and allow other threads to run.

Z

Zero-Copy

Computer operations where the CPU does not perform the task of copying data between memory contexts.
